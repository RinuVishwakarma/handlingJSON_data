# JSON Data Management Dashboard

A modern React application for managing and displaying book data in a beautiful, interactive interface.

## 🚀 Features

- 📚 **Book Library Display**
  - Modern card-based layout
  - Book cover with title initials
  - Detailed book information
  - Star ratings visualization
  - Bestseller badges

- 🔍 **Search & Filter**
  - Search books by title or author
  - Filter by genre
  - Real-time search results
  - Responsive design

- 🎨 **Modern UI**
  - Clean, minimalist design
  - Smooth hover animations
  - Responsive grid layout
  - Color-coded genre tags
  - Interactive elements

## 📋 Prerequisites

- Node.js (v14 or higher)
- npm or yarn

## 🛠️ Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd json-data
```

2. Install dependencies:
```bash
npm install
# or
yarn install
```

3. Start the development server:
```bash
npm start
# or
yarn start
```

The application will open in your default browser at `http://localhost:3000`.
